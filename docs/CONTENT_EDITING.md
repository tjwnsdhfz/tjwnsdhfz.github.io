# Notion → Obsidian → 공개 포트폴리오

- Notion `아이디어 인박스`: 빠른 원문 수집. 제목과 본문만으로 저장할 수 있습니다.
- Obsidian `raw/captures`: 사용자가 “아이디어 인박스 정리해줘”라고 요청했을 때만 URL·시각과 함께 새 스냅샷을 만듭니다.
- Obsidian Wiki: 사실·해석·목표·미확인을 나누고 문장별 승인 후 정본에 반영합니다.
- 공개 저장소: publication manifest에 허용한 정본 ID만 수동 내보냅니다.

## 직접 수정 화면

로컬 또는 공개 주소의 `/edit/`에서 다음 내용을 직접 바꿀 수 있습니다.

- 프로필 이름, 포지셔닝, 첫 문장, 소개와 프로필 사진
- 경력 4건의 기간·기관·역할·설명
- 활동 8건의 기간·활동명·기관·설명
- 프로젝트 제목·요약·직접 기여·한계·사진

편집 내용은 현재 브라우저에만 임시저장됩니다. `편집본 미리보기`로 확인한 뒤 `JSON 내려받기`를 사용하고, 검토된 파일만 `public/portfolio-content.json`과 교체합니다. 공개 편집 화면은 GitHub 토큰을 받거나 자동 게시하지 않습니다.

배포 검증 명령 `npm run content:export`는 이 편집 파일을 그대로 검사합니다. 기본 템플릿으로 다시 생성하지 않으므로 문장·사진 변경이 배포에서도 유지됩니다. 형식이 잘못된 JSON은 가져오기 전에 거절하며, 저장 공간 부족 오류가 나면 현재 화면의 편집본을 JSON으로 내려받으세요.

승격 후 Notion 원문이 바뀌면 기존 raw를 덮어쓰지 않고 새 버전으로 캡처합니다. `/edit/`의 변경도 정본 변경이 아니라 공개 후보 초안이며, 사용자 승인과 안전 검사를 거쳐야 배포할 수 있습니다.
