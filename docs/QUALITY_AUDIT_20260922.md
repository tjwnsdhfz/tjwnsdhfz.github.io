# 방문자 중심 프로젝트 설명 개선

## 수정
프로젝트에 이미 저장된 problem과 proof를 공개 화면의 문제·검증 근거 항목으로 표시한다. 본인 기여·산출물·한계도 같은 위치에 모았다. 방문자에게 노출되던 사진 파일 교체 안내와 Edit content 링크를 프로젝트 탐색 문구로 바꿨다. /edit 자체는 유지하고 공개 정보나 featured 승인 상태는 변경하지 않았다.

## 검증
lint·정적 빌드·기존 6개 검증 통과. 375px/1440px 브라우저 화면 확인, 모바일 가로 넘침 없음. 프로젝트 근거 표시와 관리자용 문구 제거 확인. 이력·역할·성과의 사실성을 새로 인증한 것은 아니다.

## 남은 실사용 검증
지원 직무별 사례 우선순위, 공개된 주장에 대한 본인 기여와 원본 증거 확인, 프로젝트별 실패 사례·재현 가이드 확충, 실제 채용 담당자의 이해도 피드백이 필요하다.
