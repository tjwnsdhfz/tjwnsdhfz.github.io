# Portfolio refresh · 2026-10-28

## User-facing changes

- Projects now follow a compact profile introduction. Demo/repository links and evidence state remain visible without expanding details.
- Each case study exposes its existing problem, role, output, evidence and limits. No career facts or project completion claims were added.
- Korean navigation, responsive case-study grid, keyboard focus, Escape-to-close mobile menu and reduced-motion support are retained.
- The local editor rejects malformed data before import, restore, preview and export. Storage failures keep the current draft available for download.
- Publication validates the edited public JSON without overwriting it with the default template. Both publication and build reject private records because the JSON itself is public.
- Pull requests now run the publication, lint, build and regression checks.

## Verification

- `npm run content:export`, `npm run lint`, `npm test`: passed (9 tests including static build checks).
- Regression tests cover malformed nested data, unsafe URLs, private records and byte-for-byte preservation of edited JSON through publication validation.
- Browser review: desktop layout, 390px mobile layout without horizontal overflow, mobile menu/Escape, gallery-to-project detail link, invalid JSON rejection with unchanged name, preview return control.
- Resolved dependency audit findings using compatible lockfile updates; installed Next.js 16.4.3. `npm audit` and `npm audit --omit=dev`: zero reported vulnerabilities at verification time.

## Limits

The editor saves locally and exports a JSON file; it does not authenticate to or publish to GitHub. BARAM remains in progress, and demo/production readiness of each separate project is not implied by the portfolio build.
